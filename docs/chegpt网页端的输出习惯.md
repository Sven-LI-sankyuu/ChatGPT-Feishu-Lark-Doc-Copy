我默认使用 **Markdown + LaTeX**。

## 公式

### 行内公式

使用 `\( ... \)` 包裹，适合嵌入句子。

源码：

```markdown
损失函数记为 \(L(\theta)\)，其中 \(\theta\) 表示模型参数。
```

显示效果：

损失函数记为 (L(\theta))，其中 (\theta) 表示模型参数。

### 独立公式

使用 `\[ ... \]` 包裹，公式单独占一行。

源码：

```markdown
\[
L(\theta)
=
-\frac{1}{N}
\sum_{i=1}^{N}
\log p_\theta(y_i\mid x_i)
\]
```

显示效果：

[
L(\theta)
=========

-\frac{1}{N}
\sum_{i=1}^{N}
\log p_\theta(y_i\mid x_i)
]

多行公式通常在其中使用 `aligned`：

```markdown
\[
\begin{aligned}
h_t &= f_\theta(x_t,h_{t-1}),\\
y_t &= g_\phi(h_t).
\end{aligned}
\]
```

显示效果：

[
\begin{aligned}
h_t &= f_\theta(x_t,h_{t-1}),\
y_t &= g_\phi(h_t).
\end{aligned}
]

我通常优先使用 `\( ... \)` 和 `\[ ... \]`，因为这组 LaTeX 定界符在聊天界面里更稳定。`$...$` 和 `$$...$$` 在一些 Markdown 环境中也常见，但容易与美元符号、普通文本或不同渲染器的规则冲突。

## 表格

表格默认使用 **Markdown 管道表格**，没有额外的外层包裹。

源码：

```markdown
| 方法 | 准确率 | 推理成本 |
|---|---:|---:|
| Baseline | 82.4% | 1.0× |
| Agent | 87.1% | 3.2× |
| Agent + Tool | 89.3% | 4.6× |
```

显示效果：

| 方法           |   准确率 | 推理成本 |
| ------------ | ----: | ---: |
| Baseline     | 82.4% | 1.0× |
| Agent        | 87.1% | 3.2× |
| Agent + Tool | 89.3% | 4.6× |

分隔行中的冒号控制对齐方式：

```markdown
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| text | text | 123 |
```

| 左对齐  |  居中  | 右对齐 |
| :--- | :--: | --: |
| text | text | 123 |

表格单元格中也可以放行内公式：

```markdown
| 符号 | 定义 |
|---|---|
| \(x_i\) | 第 \(i\) 个输入样本 |
| \(y_i\) | 对应的真实标签 |
| \(p_\theta(y_i\mid x_i)\) | 模型给出的条件概率 |
```

| 符号                      | 定义          |
| ----------------------- | ----------- |
| (x_i)                   | 第 (i) 个输入样本 |
| (y_i)                   | 对应的真实标签     |
| (p_\theta(y_i\mid x_i)) | 模型给出的条件概率   |

复杂公式、多段文字、代码块或列表不适合塞进 Markdown 表格单元格，我通常会改成分段说明或“字段：解释”的形式，避免渲染错乱。
